# CryptoPulse Live Dashboard

Live crypto dashboard streaming real Binance WebSocket data — no polling, no fake numbers.

## Stack
- Node.js (no framework, just `http` + `ws`)
- Binance public WebSocket API
- Vanilla HTML/CSS/JS frontend

## Run

```bash
npm install
npm start
```

Opens on port `3011`.

## Coins tracked
BTC, ETH, SOL, BNB, XRP, DOGE, ADA, AVAX
